# Smart Logistics Data & ML Platform

## Описание проекта
Сквозной пайплайн данных (ETL → DWH → ML) для платформы прогнозирования тарифов грузоперевозок. Реализован в рамках тестового задания.

## Архитектура
1. **Источник:** PostgreSQL 18 (локальная развертка). Схема `deals_bigdata`.
2. **ETL (`etl.py`):** Валидация данных, очистка (DQ), конвертация валют по курсу ЦБ, расчет весовых категорий. Загрузка идемпотентна (TRUNCATE + INSERT).
3. **DWH / Mart Layer (`mart.sql`):** Дедупликация справочника городов, маппинг кузовов по `std_id`. Расчет перцентилей (P25/P50/P75) и доверительных интервалов.
4. **ML (`ml.py`):** Feature Engineering (sin/cos кодирование дат, регионы), защита от утечек (исключены `price_group_stats` и `price_with_vat`). Временной сплит Train/Test. Модель **CatBoostRegressor**.

## Результаты ML на Test (Time Split)
* **R2:** 0.9141
* **MAPE:** 16.17%
* **RMSE:** 56 039 руб.
* **MAE:** 28 826 руб.

## Запуск проекта (Локально)
Проект разработан с учетом кроссплатформенности, но для проверки запускался локально (без Docker, в среде Windows + Python 3.14).

1. Разверните PostgreSQL и создайте БД `deals_bigdata`.
2. Выполните скрипты `sql/schema.sql` и `sql/synthetic.sql` (генерация 300 000 строк).
3. Выполните `init_db.sql` (создание схем `core` и `mart`).
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите ETL: `python etl.py`.
6. Запустите ML: `python ml.py`.

*Примечание: Файл `docker-compose.yml` присутствует в репозитории в качестве архитектурной заготовки. В процессе разработки Docker не использовался из-за ограничений среды, пайплайн настроен на прямое подключение к локальной БД.*
